2. GitHub 인증 3총사 개념 정리하기 🔑

3. gh CLI 디바이스 인증(Device Flow) 4단계 순서 맞추기 🪪

터미널에서 gh auth login을 실행했을 때 일어나는 순서를 1번부터 4번까지 알맞게 골라 보세요.

A. 내 PC에 안전한 암호 토큰(출입증)이 저장된다.

B. 터미널이 8자리 일회용 코드(예: A1B2-C3D4)를 발급받는다.

C. 브라우저에 8자리 코드를 입력하고 [Authorize]를 누른다.

D. 내 PC의 웹 브라우저가 GitHub 인증 페이지로 열린다.

4. 개념 점검 미니 퀴즈 & 실습 체크리스트 ⚡

문제 1. 크롬 브라우저에서 GitHub 로그인을 했으므로, VS Code 터미널에서는 별도 인증 없이도 바로 git push가 된다.
문제 2. 2FA(2단계 인증)는 '내가 아는 것(비밀번호)'과 '내가 가진 것(스마트폰)' 두 가지를 모두 확인해 계정을 지킨다.
문제 3. gh auth login의 Device Flow 방식은 터미널에 비밀번호를 직접 치지 않고 브라우저에서 안전하게 승인하는 원리다.
